# Ask the Lecture

Problem 02 — I Build It With AI Championship.

An AI study partner that sits on top of one lecture's recording and notes,
answers questions about it, and shows the student exactly where the answer came from.

## Stack
- **client** — React + TypeScript (Vite)
- **server** — Node + Express + TypeScript
- **db** — MongoDB

## Run
```bash
cd client && npm install && npm run dev
```

Scaffold only. Ingest, retrieval and citations to follow.
